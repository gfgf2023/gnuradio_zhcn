GNU Radio 伴侣 (GRC) 简体中文增强发行版 - 使用说明与硬件驱动配置指南
================================================================================

一、软件简介
本项目是 GNU Radio Companion (GRC) 的深度简体中文本地化增强版本：
1. 模块汉化：全面完成全部 575+ 个 DSP 核心模块、参数项与 20 个模块类别的中文翻译。
2. 界面风格：全面支持现代化深色暗黑（QDarkStyle）与高对比度界面。
3. 智能搜索：模块库搜索栏支持中文名、拼音缩写及原生英文标识符双向搜索。
4. 绿色便携：全功能免安装，解压即可运行，无须配置复杂编译环境。

二、快速启动
1. 双击运行【一键启动-GNU Radio中文版.bat】即可启动图形化界面。
2. 建议双击【创建桌面快捷方式.vbs】，即可在桌面生成快捷方式，后续可直接从桌面启动。
3. 若需要运行命令行脚本或硬件调试工具，请双击【启动-SDR命令行终端.bat】。

三、SDR 硬件驱动配置（Windows 环境）
本发行版已内置完整 SoapySDR、UHD 及常见 SDR 硬件插件。在 Windows 下使用 USB SDR 设备需配置驱动：

1. RTL-SDR (RTL2832U) 与 HackRF One:
   - 插入 USB 硬件到电脑；
   - 下载并运行 Zadig 驱动配置工具 (官网: https://zadig.akeo.ie/)；
   - 打开 Zadig，在顶部菜单选择【Options】 -> 勾选【List All Devices】；
   - 在主下拉列表中选择你的设备（如 "Bulk-In, Interface (Interface 0)" 或 "HackRF One"）；
   - 将目标驱动选择为【WinUSB】，然后点击【Replace Driver】或【Install Driver】；
   - 验证：双击打开【启动-SDR命令行终端.bat】，输入 `SoapySDRUtil --find`，若显示探测到硬件则说明配置成功。

2. ADALM-PLUTO (PlutoSDR):
   - 使用 Micro-USB 线缆连接电脑；
   - 访问 Analog Devices 官方网站下载安装 "PlutoSDR Windows Driver"；
   - 确认设备在网络连接中获得 192.168.2.1 的 IP 地址；
   - 在流图中添加 IIO 设备模块或 SoapySDR PlutoSDR 模块即可收发信号。

3. USRP (Ettus Research):
   - 若使用千兆/万兆网口 USRP（如 USRP N210 / X300 / X310），请在 Windows 网络适配器中将本机的以太网卡配置为静态 IP（例如 192.168.10.1 / 掩码 255.255.255.0）；
   - 在【启动-SDR命令行终端.bat】中运行 `uhd_find_devices` 查看设备握手状态。

四、常见问题与解决
1. Q: 点击“生成代码”或“运行”无反应？
   A: 请先确保流图已经保存为 .grc 文件，且流图中没有红色报警（未连接或参数错误）。若有错误，请在界面底部【控制台】选项卡中查看详细日志。
2. Q: 界面文字显示过小或高分屏缩放不正常？
   A: 可在“工具” -> “偏好设置”中调节界面缩放比例，或通过系统高 DPI 设置调整。
3. Q: 模块库未找到某些硬件模块？
   A: 请在搜索栏直接输入硬件中文名（如“信号源”、“示波器”、“HackRF”、“Pluto”或“USRP”）。
